## 项目简介

MeowGuard 是一个以技术驱动的流浪猫救助平台，通过智能猫屋 + 计算机视觉 + 云端协作，解决流浪猫"管理难、救助难、领养难"的社会问题。

此 MVP 为软件原型，通过 Web 界面模拟核心功能：
- 📹 **24 小时慢直播** — 模拟猫咪直播间，实时环境监测
- 🍖 **远程投喂** — 一键投喂，记录透明可追溯
- 📋 **猫咪档案** — AI 建档，健康状态与互动数据一目了然
- 🏠 **领养中心** — 分阶段过渡计划，保障猫咪与领养人双向权益
- 📱 **PWA 支持** — 可添加到手机主屏幕，离线可访问
- 📄 **独立演示页** — 打开 `demo.html` 无需任何依赖

## 技术栈

| 层级 | 技术 |
|------|------|
| **后端** | Python 3.6+ · Flask |

## 快速开始

### 方式一：Flask 完整版（推荐）

**1. 安装 Python**

确保已安装 Python 3.6+：
```bash
python --version
```

**2. 安装依赖**
```bash
pip install flask
# 或使用 requirements.txt
pip install -r requirements.txt
```

**3. 启动服务**
```bash
python app.py
```

**4. 访问网站**

打开浏览器访问：**http://localhost:5000**

## 功能说明

### 🏠 首页 — 直播间
- 模拟猫咪直播画面（含猫猫弹跳动画）
- 实时统计：在线观众、今日投喂、累计投喂
- 点击 **"投喂猫咪"** 按钮触发粒子特效 + 日志记录
- 右侧面板：投喂记录、环境监测（温度/湿度/空气质量）、当前猫咪信息

### 🐱 猫咪档案
- 网格卡片展示所有建档猫咪
- 标签筛选：性别、年龄、毛色、绝育状态、是否可领养
- 点击卡片查看详情弹窗：
  - 基本信息（性别、年龄、毛色）
  - 绝育状态与健康评估
  - 位置信息（隐私保护提示）
  - 互动数据（累计投喂、累计观看）

### 🏠 领养中心
- 展示可领养猫咪列表
- 填写领养申请表（模拟）
- 提交后显示成功提示

### 📱 PWA 功能
- 通过浏览器"添加到主屏幕"可像原生 App 使用
- 支持离线访问（已缓存关键资源）

## API 接口

| 接口 | 方法 | 说明 |
|------|------|------|
| `/` | GET | 首页（直播间） |
| `/cats` | GET | 猫咪档案页 |
| `/adopt` | GET | 领养中心页 |
| `/api/cats` | GET | 获取所有猫咪列表 |
| `/api/cat/<id>` | GET | 获取单个猫咪详情 |
| `/api/stats` | GET | 获取统计数据 |
| `/api/feed` | POST | 投喂猫咪 |
| `/api/feed-logs` | GET | 获取投喂记录 |
| `/api/adopt/apply` | POST | 提交领养申请 |

## 后续扩展方向

基于 MeowGuard 完整愿景，此 MVP 的后续演进方向：

1. **AI 猫脸识别** — 基于 YOLOv8 + ResNet，实现猫咪自动建档、剪耳标记识别、健康预警
2. **智能猫屋硬件** — 集成温湿度传感器、自动出粮、太阳能供电、夜视摄像头的实体设备
3. **用户系统** — 多角色登录（云养人 / 志愿者 / 物业 / 领养人），实名认证对接公安数据库
4. **支付闭环** — 微信支付 / 支付宝接入，支持云投喂、月捐计划、可退还领养保障金
5. **社区治理 SaaS** — 向物业 / 街道办提供治理数据报表与 ROI 看板
6. **分阶段领养系统** — 线上试养 → 月度过渡 → 稳定期 → 终身关怀的四阶段过渡计划
7. **猫咪日记** — LLM 自动生成微观日记 + 用户共创 UGC 内容
8. **区块链存证** — 电子领养协议上链，确保不可篡改
