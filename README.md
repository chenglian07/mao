# 🐱 项目猫 - 最小原型 (MVP)

> 让每一只流浪猫都有自己的直播间，让每一份爱心都不被浪费，让每一个生命都被温柔以待。

## 项目简介

这是一个纯软件模拟的"项目猫"最小原型，用于课程作业展示。通过 Web 界面模拟智能猫屋的核心功能：
- 📹 **24 小时慢直播** - 模拟猫咪直播间
- 🍖 **远程投喂** - 点击按钮即可投喂猫咪
- 📋 **猫咪档案** - 查看每只猫咪的详细信息
- 🏠 **领养中心** - 模拟领养申请流程

## 技术栈

- **后端**: Python Flask
- **前端**: HTML + CSS + JavaScript (原生，无需框架)
- **数据存储**: JSON 文件 (无需数据库)

## 快速开始

### 1. 安装 Python

确保已安装 Python 3.6+：
```bash
python --version
```

### 2. 安装依赖

```bash
pip install flask
```

或者使用 requirements.txt：
```bash
pip install -r requirements.txt
```

### 3. 运行项目

```bash
python app.py
```

### 4. 访问网站

打开浏览器访问：http://localhost:5000

## 功能说明

### 首页 - 直播间
- 显示模拟的猫咪直播画面
- 实时统计在线观众、投喂次数
- 点击"投喂猫咪"按钮进行互动
- 显示投喂记录和环境监测数据

### 猫咪档案
- 查看所有猫咪的列表
- 按状态筛选 (全部/可领养/已绝育)
- 点击查看详情，包括：
  - 基本信息 (性别、年龄、毛色)
  - 健康状况
  - 位置信息
  - 互动数据

### 领养中心
- 查看可领养的猫咪
- 填写领养申请表
- 提交后显示成功提示

## API 接口

| 接口 | 方法 | 说明 |
|------|------|------|
| `/` | GET | 首页 |
| `/cats` | GET | 猫咪档案页 |
| `/adopt` | GET | 领养中心页 |
| `/api/cats` | GET | 获取所有猫咪列表 |
| `/api/cat/<id>` | GET | 获取单个猫咪详情 |
| `/api/stats` | GET | 获取统计数据 |
| `/api/feed` | POST | 投喂猫咪 |
| `/api/feed-logs` | GET | 获取投喂记录 |
| `/api/adopt/apply` | POST | 提交领养申请 |
