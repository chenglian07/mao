# CatTrace

> 基于 AIoT 的流浪猫科学救助与社区共治平台

## 项目简介

CatTrace 是一个面向社区、校园、公园等场景的流浪猫科学救助平台。通过在猫咪活动区域部署智能猫屋，结合远程投喂、在线巡检和个体化档案管理，帮助志愿者和爱心人士更高效地参与流浪猫救助与管理。

## 解决什么问题

- 流浪猫缺乏持续跟踪，个体信息难以记录和管理
- 投喂行为分散，无法追溯谁在何时喂了哪只猫
- 志愿者巡检效率低，缺少远程查看猫咪状态的工具
- 社区治理缺乏数据支撑，救助流程不透明

## 技术架构

| 层级 | 技术选型 | 说明 |
|------|---------|------|
| 后端 | Python 3.6+ / Flask | 轻量 REST API 服务 |
| 前端 | HTML5 + CSS3 + JavaScript | 原生开发，无框架依赖 |
| 存储 | JSON 文件（原子写入） | MVP 阶段轻量方案 |
| 分析引擎 | Python 标准库 | 统计分析 + 规则引擎 + 异常检测 |
| 边缘节点 | Raspberry Pi 4 Model B + 摄像头 + 传感器 | 待硬件接入（正在烧录系统，尚未部署） |
| PWA | Service Worker + manifest | 支持离线访问 |

详见 [docs/architecture.md](./docs/architecture.md)。

## 三大核心能力

### 一、实时直播与在线巡检

通过摄像头接入猫屋画面，用户可远程查看猫咪状态和环境数据。

- 摄像头画面接入、在线状态查看（后端 API 已就绪，当前前端为模拟画面）
- 环境传感器数据展示（温度、湿度）
- 当前状态：**待硬件接入** — 网页和后端 API 已就绪，尚未接入真实摄像头和传感器

### 二、远程投喂与投喂追溯

用户可对指定猫咪执行投喂操作，系统记录完整投喂链路，支持查询和导出。

- 登录用户无限投喂，游客限 1 次
- 投喂记录全链路可追溯（谁、何时、喂了哪只猫）
- 自学习引擎自动分析投喂规律、检测异常投喂
- 当前状态：**软件已实现，待验证** — 投喂记录为软件层面操作，自学习分析基于预置数据，尚未对接真实投喂设备

### 三、猫咪档案与个体化救助

为每只建档猫咪创建数字身份档案，支持健康管理、日记记录和领养匹配。

- 猫咪基本信息、健康状态、绝育记录、位置信息管理
- 猫咪日记（人工撰写）、点赞与评论互动
- 健康评分（基于投喂规律和情绪数据的规则引擎分析）
- 领养申请管理（含资格审核流程）
- 当前状态：**软件已实现，待验证** — AI 猫咪身份识别为规划中，日记为人工撰写，档案数据为预置

### 支撑功能

用户认证（手机号 + 验证码）、预警中心（异常投喂/行为检测）、透明看板（财务数据展示）、领养管理、举报与紧急求助、志愿者管理、通知系统。以上支撑功能的后端接口均已实现，部分功能页面尚待补充。详见各模块文档。

## 快速开始

### Flask 完整版（推荐）

```bash
python --version   # 需要 3.6+
pip install -r requirements.txt
python app.py
# 浏览器打开 http://localhost:5000
```

页面路由：`/`（首页直播）、`/cats`（猫咪档案）、`/diary`（日记）、`/adopt`（领养中心）。

### 静态演示页（零依赖）

双击打开 `demo.html`，无需 Python 环境。详见 [docs/demo-guide.md](./docs/demo-guide.md)。
