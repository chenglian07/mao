# CatTrace 自学习模块说明

自学习不是 CatTrace 的独立功能，而是贯穿三大核心功能的 AI 能力层。本文档说明自学习模块的目标、边界、数据闭环、分功能子能力、优先级和评价指标。

---

## 1. 目标与边界

### 1.1 目标

根据用户反馈和平台运行数据，持续优化以下三类输出：

- **投喂提醒**：根据每只猫的历史投喂规律，动态调整异常投喂告警阈值，减少误报。
- **健康异常判断**：基于进食规律、情绪稳定性、活跃趋势等指标计算健康评分，并根据反馈校准评分参数。
- **猫咪识别辅助**：收集用户对猫脸识别结果的纠错反馈，为后续模型训练积累标注数据。

### 1.2 边界

| 约束 | 说明 |
|------|------|
| 不做自动决策 | 自学习模块不自动执行救助、领养、绝育等业务决策。所有输出均为建议或告警，由人工确认后执行。 |
| 模型更新需审核 | 任何规则参数或模型权重的变更，必须经过人工审核后才能生效，不允许自动上线。 |
| 可回滚 | 每次规则或模型更新均记录版本号，支持一键回滚到上一个稳定版本。 |
| MVP 不做在线深度学习 | 当前阶段仅实现反馈采集和基于统计的规则自校准，不引入在线梯度下降、增量训练等深度学习方法。 |

## 2. 数据闭环

自学习模块的数据流遵循以下闭环：

```
用户操作 / 视频样本
       |
       v
结构化反馈采集
       |
       v
数据清洗与聚合
       |
       v
规则或模型候选更新
       |
       v
人工审核
       |
       v
版本发布
       |
       v
效果评估
       |
       v
(回到起点，持续迭代)
```

### 各环节说明

| 环节 | 输入 | 输出 | 当前实现 |
|------|------|------|---------|
| 结构化反馈采集 | 投喂日志、用户纠错、举报事件 | feedback_log、anomaly_records | 已实现 |
| 数据清洗与聚合 | 原始日志 | 猫咪画像(cat_profiles)、用户画像(user_prefs) | 已实现 |
| 规则候选更新 | 聚合数据 | 新阈值、新评分参数 | 已实现（统计规则） |
| 人工审核 | 候选更新 | 审核通过 / 拒绝 / 修改 | 规划中 |
| 版本发布 | 审核通过的参数 | 新版本规则文件 | 规划中 |
| 效果评估 | 新版本运行数据 | 误报率、准确率等指标 | 规划中 |

**注意**：以上"已实现"环节基于 4 只预置猫的模拟数据运行，代码逻辑完整但未经真实运营数据验证。

## 3. 分功能子能力

### 3.1 实时直播与在线巡检

异常行为检测与低置信度样本标注依赖硬件摄像头实际接入，当前 MVP 阶段暂未实现。详见 [user-guide.md](./user-guide.md)。

### 3.2 远程投喂与投喂追溯

已实现投喂规律学习、异常投喂提醒、阈值自校准。基于 Python 标准库的统计分析，数据持久化于 data.json 的 learning 字段。

### 3.3 猫咪档案与个体化救助

已实现健康评分与规则校准。猫脸识别辅助建档规划中。详见 [user-guide.md](./user-guide.md)。

---

## 4. 优先级

| 等级 | 能力 | 说明 |
|------|------|------|
| P0 | 反馈采集 | 记录用户投喂行为、纠错反馈、举报事件。这是所有后续学习的基础，MVP 必须实现。 |
| P1 | 规则自校准 | 基于累积数据自动调整告警阈值和评分参数。已实现基础版本（统计规则）。 |
| P2 | 半自动标注与版本管理 | 低置信度样本请求人工标注，规则更新需审核并可回滚。规划中。 |
| P3 | 在线学习 / 联邦学习 | 实时流数据增量训练、多节点模型协同。远期规划，不纳入 MVP。 |

---

## 5. 评价指标

| 指标 | 定义 | 目标值 | 当前状态 |
|------|------|--------|---------|
| 反馈记录完整率 | 用户纠错反馈被正确记录的比例 | >= 95% | 已实现基础采集 |
| 规则调整后误报率 | 阈值自校准后，异常投喂告警的误报率 | < 10% | 待评估（需积累运行数据） |
| 人工审核通过率 | 候选规则更新经人工审核后的通过比例 | >= 80% | 规划中（审核流程未实现） |
| 回滚次数 | 规则更新后因效果不佳而回滚的次数 | 越少越好 | 规划中（版本管理未实现） |

---

## 6. 技术实现概述

### 6.1 当前版本（v1.0）

- **实现方式**：纯 Python 标准库（collections.Counter、collections.defaultdict），无外部 ML 依赖。
- **数据存储**：JSON 文件（data.json 的 learning 字段）。
- **核心类**：SelfLearningEngine（self_learning.py）。
- **能力范围**：统计分析 + 规则引擎 + 基础异常检测。
