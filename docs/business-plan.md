# CatTrace 商业与技术计划

本文档整合 CatTrace 的市场分析、产品设计、技术方案和商业规划，作为项目唯一的商业计划文档。

---

## 1. 市场背景

### 1.1 行业数据

| 数据 | 说明 |
|------|------|
| 5000-8000 万只 | 中国流浪猫数量，且持续增长 |
| 3 亿+ | "云吸猫"用户，想看猫但养不了 |
| 2793 亿元 | 2024 年中国宠物经济规模 |

### 1.2 四方痛点

| 角色 | 困难 | CatTrace 的解法 |
|------|------|----------------|
| 爱心人士 | 想喂猫找不到，不知道钱花哪了 | 远程投喂 + 透明记录 |
| 物业/社区 | 猫扰民投诉多，左右为难 | 数据化治理工具 |
| 志愿者 | 找猫靠蹲、领养靠运气 | 智能定位 + 高效匹配 |
| 领养人 | 怕猫有病、怕"星期猫" | 真实档案 + 严选流程 |

### 1.3 核心思路

```
智能猫屋（硬件）  -->  数据采集（AI 识别）  -->  平台管理（软件）
      |                      |                      |
  投喂/直播            猫咪数字身份         投喂->绝育->领养->治理
```

---

## 2. 产品定位

**项目名称**：CatTrace -- 流浪猫科学救助平台
**项目性质**：课程实践项目
**当前版本**：MVP v3.0

CatTrace 在小区、校园、公园部署智能猫屋，让用户在手机上看到猫咪、远程投喂、申请领养，同时帮助物业和志愿者科学管理流浪猫。

---

## 3. 产品范围

### 3.1 三大核心功能（P0）

| 功能 | 状态 | 一句话说明 |
|------|------|-----------|
| 实时直播与在线巡检 | 待硬件接入 | Raspberry Pi 4 Model B 边缘节点推流，远程查看猫咪状态（正在烧录系统，外设选型待定） |
| 远程投喂与投喂追溯 | 软件已实现，待验证 | 一键投喂，全链路记录，数据透明可追溯（自学习分析基于预置数据，待真实数据验证） |
| 猫咪档案与个体化救助 | 软件已实现，待验证 | 每只猫的数字身份：基本信息、健康、绝育、互动数据（档案为预置数据，AI 识别规划中） |

各功能的详细使用说明、验收标准，请参阅 [user-guide.md](./user-guide.md)。

### 3.2 辅助功能

| 功能 | 等级 | 状态 | 说明 |
|------|------|------|------|
| 用户认证（手机号 + 验证码） | P0 | 网页已完成 | 页面、接口、前端逻辑均完整 |
| 猫咪日记 | P1 | 网页已完成 | 页面、接口均完整；日记为人工撰写，非 AI 生成 |
| 领养申请 | P1 | 网页已完成 | 申请和资格审核可用；无后续跟进/回访机制，不构成完整领养业务闭环 |
| 举报与紧急求助 | P1 | 软件部分实现 | 后端接口可用；无独立举报页面，仅通过 API 操作 |
| 位置脱敏（三级隐私） | P1 | 软件已实现，待验证 | 接口逻辑完整；基于预置数据运行，待真实场景验证 |
| 财务透明看板 | P1 | 软件部分实现 | 后端 API 可返回模拟数据；`dashboard.html` 模板缺失，页面不可访问 |
| 志愿者管理 | P2 | 软件部分实现 | 后端接口可用；无独立志愿者管理页面 |
| 通知系统 | P2 | 软件部分实现 | 后端接口可用；`/api/notifications/unread-count` 固定返回 0，无推送机制 |

## 4. 技术方案

### 4.1 技术栈

| 层级 | 技术 | 说明 |
|------|------|------|
| 后端 | Python 3.6+ / Flask | 轻量 REST API |
| 前端 | HTML5 + CSS3 + JS | 原生开发，零框架依赖 |
| 数据 | JSON 文件存储 | 原子写入保安全 |
| 自学习 | Python 内置算法 | 统计 + 模式识别 + 异常检测 |
| PWA | Service Worker | 离线可访问 |

### 4.2 硬件方案

#### 边缘节点（直播主力）

| 组件 | 选型 | 说明 |
|------|------|------|
| 主板 | Raspberry Pi 4 Model B | 运行 Linux，负责摄像头推流与数据上报 |
| 摄像头 | 待确定 | MJPEG 推流或快照轮询（CSI / USB 接口待定） |
| 环境传感器 | 待确定 | 温湿度 / 空气质量等，通过 GPIO 采集（型号和接线方案待定） |
| 供电 | 待确定 | 太阳能板 + 锂电池（户外场景）或适配器供电（室内场景） |
| 网络 | WiFi / 4G 模块 | 上报数据至云端平台 |

**注意**：以上为参考方案，Raspberry Pi 4 Model B 正在烧录系统，具体摄像头型号、传感器型号、GPIO 接线及通信方案尚待硬件选型验证后确定。

#### 可选传感器扩展节点

| 组件 | 选型 | 说明 |
|------|------|------|
| 主板 | ESP32 | 低成本独立传感器节点 |
| 传感器 | 温湿度 / 光照 / 红外 | 通过 WiFi 上报至平台 |
| 定位 | 可选 GPS 模块 | 辅助猫屋选址与位置记录 |

ESP32 不作为直播推流设备，仅用于轻量传感器数据采集与上报。
