# 社区共治与支撑功能

> 支撑功能模块 | 等级：P1-P2 | 状态：**软件部分实现**

本文档涵盖 CatTrace 中除三大核心能力之外的支撑功能，包括领养管理、社区共治（举报与志愿者）、预警中心、财务透明看板和通知系统。

---

## 用户认证

**状态**：已实现

| 能力 | 接口 | 说明 |
|------|------|------|
| 登录 | `POST /api/auth/login` | 手机号 + 验证码（MVP 固定验证码 8888） |
| 用户信息 | `GET /api/auth/me` | 获取当前登录用户信息 |
| 退出 | `POST /api/auth/logout` | 清除 Token |

用户注册功能当前未实现独立接口，用户数据通过初始化数据或登录流程自动创建。

## 举报与紧急求助

**状态**：已实现

| 能力 | 接口 | 说明 |
|------|------|------|
| 提交举报 | `POST /api/report` | 支持普通举报和紧急求助 |
| 举报列表 | `GET /api/reports` | 支持按状态和猫咪筛选 |
| 紧急求助列表 | `GET /api/emergency/alerts` | 位置信息脱敏显示 |
| 解决求助 | `POST /api/emergency/alert/<id>/resolve` | 管理员操作 |

紧急举报（`is_emergency=true`）会自动创建求助警报，通知志愿者。

举报状态流转：`pending` → `reviewing` → `resolved` / `dismissed`

## 志愿者管理

**状态**：已实现

| 能力 | 接口 | 说明 |
|------|------|------|
| 申请志愿者 | `POST /api/volunteer/apply` | 填写个人信息和可用时间 |
| 志愿者列表 | `GET /api/volunteers` | 脱敏显示（不暴露身份证号等） |

志愿者等级：`volunteer` → `senior_volunteer` → `coordinator`

认证志愿者可查看猫咪精确位置（见 [猫咪档案](./cat-profile.md) 位置脱敏规则）。

## 预警中心

**状态**：软件部分实现（规则引擎驱动）

预警能力由自学习引擎提供，基于统计规则而非机器学习模型。当前无独立预警页面，异常数据仅通过 API 可查：

| 预警类型 | 触发条件 | 严重程度 |
|---------|---------|---------|
| 过度投喂 | 单日投喂超均值 2 倍 | medium |
| 猫咪失踪 | 3 天以上无投喂记录 | medium/high |
| 情绪异常 | 主导情绪为"警惕""低落""不安" | low |
| 健康异常 | 健康评分低于 50 分 | high |

查询接口：`GET /api/learning/anomalies`

**注意**：预警基于规则引擎分析结果，非 AI 模型判断。可能存在误报，需人工确认。

## 财务透明看板

**状态**：软件部分实现

| 能力 | 接口 | 说明 |
|------|------|------|
| 财务概览 | `GET /api/finance/summary` | 收支统计、本月数据、分类统计 |
| 交易记录 | `GET /api/finance/transactions` | 支持筛选和分页 |
| 月度趋势 | `GET /api/finance/monthly` | 按月收支数据 |
| 看板页面 | `GET /dashboard` | ⚠️ 模板文件 `dashboard.html` 不存在 |

**注意**：
- 财务数据为预置模拟数据，非真实运营数据
- `/dashboard` 页面路由存在，但 `dashboard.html` 模板文件缺失，访问会报错
- 后端 API 接口可正常返回模拟数据，但用户无法通过页面访问

## 通知系统

**状态**：已实现（基础版）

| 能力 | 接口 | 说明 |
|------|------|------|
| 通知列表 | `GET /api/notifications` | 从投喂日志和紧急求助生成通知 |
| 未读数量 | `GET /api/notifications/unread-count` | 当前固定返回 0 |

通知来源：
- 最近的投喂记录（最近 10 条）
- 活跃的紧急求助（最近 5 条）

## 数据导出

**状态**：已实现

`GET /api/export` 返回全量 JSON 数据，包含所有猫咪档案、投喂记录、日记、领养申请、举报记录等。
