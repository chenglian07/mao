# 猫咪档案与个体化救助

> 核心能力三 | 等级：P0 | 状态：**软件已实现，待验证**

---

## 功能定位

为每只建档的流浪猫创建完整的数字身份档案，包含基本信息、健康状态、绝育记录、位置信息和互动数据。档案页（`/cats`）是用户浏览猫咪、了解猫咪详情的主要入口。

**重要说明**：当前猫咪档案为人工建档（系统预置 4 只示例猫咪），尚未实现 AI 猫咪身份自动识别。猫咪绝育状态（`neutered` 字段）用于 TNR 救助管理参考，不构成完整的绝育管理系统。

## 使用步骤

1. 点击导航栏"猫咪档案"进入档案页（`/cats`）。
2. 页面展示所有建档猫咪的卡片列表。
3. 使用筛选栏按条件过滤：全部 / 可领养 / 已绝育 / 需关注。
4. 使用搜索框按名字、昵称、位置搜索。
5. 点击猫咪卡片展开详情面板，查看完整档案和投喂趋势图表。

## 健康评分

健康评分由自学习引擎的规则引擎计算（**非机器学习模型**）：

```
健康分 = 基础分(70) + 进食规律分(0-15) + 情绪稳定分(0-10)
       + 活跃趋势分(0-5) - 异常扣分(0-30)
```

| 分数区间 | 建议 |
|---------|------|
| ≥ 85 | 状态很好，继续保持 |
| ≥ 70 | 状态正常，可以多加关注 |
| ≥ 50 | 需要关注，建议志愿者实地查看 |
| < 50 | 状态异常，请尽快安排检查 |

查询接口：`GET /api/learning/health-report/<id>`

## 验收标准

1. 档案页正常加载，展示所有猫咪卡片，字段完整。
2. 筛选功能（全部/可领养/已绝育/需关注）正确过滤。
3. 搜索功能可按名字、昵称、位置模糊匹配。
4. 点击猫咪卡片后，详情面板展示完整档案信息。
5. 投喂趋势图表正确渲染，数据与实际投喂记录一致。
6. 健康评分接口返回 0-100 范围内的数值。

## 后续规划

- AI 猫脸识别辅助建档（通过照片自动识别猫咪身份）
- 剪耳识别辅助 TNR 管理
- 猫咪行为自动分类（基于视频分析）
- 与真实传感器/摄像头数据联动更新档案

AI 识别能力依赖摄像头实际接入和训练数据积累，当前阶段以人工建档为主。AI 对猫咪身份或剪耳情况的判断不能直接当作人工确认事实，需人工验证后才能写入正式档案。
