# 实时直播与在线巡检

> 核心能力一 | 等级：P0 | 状态：**待硬件接入**

---

## 功能定位

在小区、校园、公园的智能猫屋部署摄像头与环境传感器，让用户和志愿者远程实时查看猫咪状态，巡查猫屋运行情况。

该功能对应平台首页（`/`），是用户进入平台后的第一个交互界面。

### 状态说明

- **网页已完成**：`index.html` 页面、后端 API、前端交互逻辑均已实现，可通过浏览器正常访问和操作
- **待硬件接入**：后端 `/api/camera/*` 系列接口已就绪，但尚未接入真实摄像头和传感器设备；Raspberry Pi 4 Model B 正在烧录系统，外设选型待定

## MVP 阶段表现

- **直播画面**：前端展示模拟画面（含猫咪动画），非真实视频流
- **温度/湿度**：前端随机生成（温度 20-35°C，湿度 40-80%），每 5 秒刷新
- **今日投喂次数**：从后端 `/api/stats` 获取真实数据
- **在线观看人数**：模拟固定值

## 使用步骤

1. 打开平台首页，页面自动加载直播区域。
2. 直播区域展示当前猫屋画面（MVP 阶段为模拟画面）。
3. 页面底部环境数据栏显示温度、湿度、今日投喂次数。
4. 点击"投喂一份"按钮可在直播页面直接发起投喂。
5. 点击"当前猫咪信息"按钮可查看猫咪档案摘要。

## 接入真实硬件

Raspberry Pi 4 Model B 正在烧录操作系统，具体摄像头型号和传感器选型待确定。系统就绪后，配置环境变量指向树莓派地址即可接入：

```bash
export CATTRACE_CAMERA_URL=http://192.168.1.100:8080
python app.py
```

边缘节点部署详见 [raspberry_pi/README.md](../../raspberry_pi/README.md)。

## 验收标准（MVP）

1. 首页正常加载，直播区域显示模拟画面与环境数据。
2. 环境数据按固定间隔刷新，数值在合理范围内波动。
3. 点击"投喂"按钮正常跳转至投喂流程。
4. 页面在移动端浏览器中可正常显示与交互。
